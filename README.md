# Ozon Seller Desk

Легковесный кабинет для управления магазинами Ozon: регистрация пользователей, восстановление пароля по email, подключение магазинов и выгрузка товаров с расчётом маржинальности.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Переменные окружения (опционально) задайте через `.env`:

- `SECRET_KEY` — секретный ключ Flask.
- `DATABASE_URL` — путь к базе (по умолчанию `sqlite:///app.db`).
- `MAIL_SERVER`, `MAIL_PORT`, `MAIL_USE_TLS`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_DEFAULT_SENDER` — SMTP для отправки ссылок восстановления.

## Основные возможности
- Регистрация, вход, выход и сброс пароля через email-ссылку.
- Дашборд с краткими метриками.
- Администратор (`ADMIN_EMAIL`/`ADMIN_PASSWORD`) видит все магазины/товары и может ограничивать возможности пользователей.
- Управление магазинами Ozon (название, Client ID, Api Key) с хранением в базе.
- Страница «Товары»:
  - Запросы к `/v3/product/list`, `/v3/product/info/list`, `/v5/product/info/prices`, `/v1/analytics/average-delivery-time/summary` через сохранённые ключи магазина.
  - Таблица с фильтрами по каждой колонке, пересчёт выручки/маржи при изменении цены или наценки прямо в таблице.
  - Сохранение последней выборки в базе для автономного просмотра.
- Страница «Заказы»:
  - Выбор магазина и периода, загрузка отправлений по FBO/FBS с API `/v3/posting/fbs/list` и `/v2/posting/fbo/list`.
  - Сводные показатели по заказам и раскрывающиеся расходы по позициям с артикулами.

## Замечания по работе
- При отсутствии настроенного SMTP письмо восстановления выводится в консоль приложения.
- Если у ключей нет доступа к отдельным методам Ozon, ошибки показываются во всплывающих уведомлениях.
